# HR Analytics Dashboard 📊

## 📌 Project Overview

The HR Analytics Dashboard is an Excel-based data analysis and visualization project developed to analyze employee information and present meaningful workforce insights through an interactive dashboard.

The project uses employee-level HR data, Excel formulas, Pivot Tables, charts, and slicers to transform raw employee data into an easy-to-understand visual dashboard.

## 🎯 Objective

The main objective of this project is to analyze employee data and develop an interactive HR Analytics Dashboard that provides a clear overview of the organization's workforce.

The project aims to:

* Analyze employee demographics and workforce composition.
* Examine employee distribution across departments.
* Analyze gender and employment-related information.
* Analyze work locations and employee distribution.
* Examine employee performance-related information.
* Provide interactive filtering using Excel slicers.
* Present HR insights in a clear and visually understandable format.
* Demonstrate practical data analysis and dashboard development skills using Microsoft Excel.

## 📊 Dataset

The dataset contains information about 50 employees and includes multiple employee-related attributes used for HR analysis.

The dataset includes information related to areas such as:

* Employee information
* Gender
* Age
* Department
* Work location
* Employment-related attributes
* Performance-related attributes
* Other HR-related information used in the dashboard
